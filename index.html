Cyber Intrusion

Detects unauthorized SSH brute-force attempts or socket-level port scanning.

Healing Method: Immediate termination of malicious PIDs and dynamic firewall rule generation to blacklist intruder IP addresses.

Connectivity Stalls

Heals "Zombie Connections" where the hotspot is active but data packets are dropped.

Healing Method: Automated flushing of the DNS resolver cache and re-initialization of the Virtual Network Interface (wlan0).

Resource Saturation

Monitors RAM heap growth to prevent system freeze caused by memory leaks.

Healing Method: Triggers aggressive Garbage Collection (GC) and recycles background worker threads to reclaim leaked RAM.

The MAPE-K Operational Loop

Monitor: Collects heartbeats and resource logs from the computing node.

Analyze: Compares real-time data against known "Health Thresholds" to find faults.

Plan: Selects the optimal recovery script (e.g., Firewall block vs. RAM flush).

Execute: Applies the fix via System Effectors and verifies restoration.
